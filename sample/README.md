# Sample project

`fra_mauro_sample.sqlite3` is a deliberately synthetic workflow demonstration. Its control points and coordinates are not historical claims and must not be reused as research data.

To inspect it, open **Export** in the app and restore the sample database. This replaces the current app database, so first download a backup of any real work.

Regenerate the sample from the repository root with:

```bash
python -m scripts.create_sample_db
```
